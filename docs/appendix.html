付録：本書で語らなかったもの

本付録は、本文では詳しく扱わなかった射程の制限や、標準的な数学書との記法上の違いを整理したものである。本文の導入は意図的に非標準的であるため、読者が標準理論へ進む際に誤解しやすい点を、ここでまとめて補足する。

本書は、一般多様体上の微分形式論を公理的に展開する本ではない。3次元ユークリッド空間におけるベクトル解析を、行列表示の微分形式を通して再構成するための教育的な本である。したがって、本書で採用した記法や説明順序は、標準的な数学書の記述と一致しない箇所がある。

I. 理論的枠組みと射程について

  • 多様体、アトラス、接空間などの数学的定義なしに外微分を導入するのは不正確である

    • → 本書は一般多様体上の微分形式の教科書ではなく、3次元ユークリッド空間上でベクトル解析へ到達するための導入書である。一般多様体への移行については第11章で道標を示す。

  • 反変ベクトルと共変ベクトル（双対空間）の区別を序盤で明確にすべきである

    • → 第1章 §1.1.6 で「縦ベクトル（変位）」と「横ベクトル（測定器）」の区別を導入しており、これは双対空間の概念の具体的な実装である。より抽象的な双対空間の定式化については第6章および第11章で接続する。

  • $dx$ を横ベクトルとして扱う記法は数学書の標準的な表記ではない

    • → 意図的な選択である。第1章 §1.1 で定義し、全章で一貫して使用している。この記法の狙いは「1-form = ベクトルを食べる関数」という抽象概念を、読者が既知の「行列の掛け算」に翻訳することにある。標準的な微分形式の記法（$\omega \in \Omega^1(M)$ 等）との対応は第11章で示す。

  • 外微分 $d$ は公理（ライプニッツ則や $d^2=0$）から一般的に定義すべきである

    • → 本書では公理から始めるのではなく、第5章 §5.3 で「微小ループを一周したときのズレ」という直感から発見的に $d$ を導出している。$d^2=0$ も第5章で混合偏微分の対称性に関連付けて理解する。公理的定義は第11章で補足する。

  • 一般の $n$ 次元多様体におけるストークスの定理の完全な証明が記載されていない

    • → 本書では3次元空間での具体的なケース（ストークス、ガウス、グリーン）を積分の定義から直接導出する（第5章、第8章）。一般次元のストークスの定理の証明は本書の射程外であり、第11章で道標のみ示す。

  • ウェッジ積の定義において外積代数の普遍性質を用いた公理的アプローチを経由していない

    • → 本書では第2章 §2.4 でテンソル積の反対称化としてウェッジ積を構築している。これは公理的アプローチの具体的な実装であり、読者が行列の引き算として手を動かせるようにするための意図的な選択である。

  • 標準的な記法を避けているため、独自流派を主張しているように見える

    • → 本書の記法は「初学者が行列計算で手を動かせる」ことに特化して選ばれている。標準的な記法（添字による縮約、$\partial_\mu$ 等）との対応は第11章で説明している。この方針自体は数値計算の分野などでは広く見られるもので、新しい数学を主張するものではない。

II. 手法の選択と適用限界について

  • アインシュタインの縮約記法（テンソル解析）を用いれば行列の束を使わずとも計算できる

    • → その通りである。本書では、行列の成分を明示的に書き下す方針をとっている。これにより、読者は各成分がどこから来て、どこへ作用するのかを可視化した状態で追うことができる。本書を読みこなした読者なら、添字の上下の規則を練習するだけでテンソル解析へ比較的すぐ移行できるはずである。

  • 最初からクリフォード代数（幾何代数）を教えれば外積も内積も統合できる

    • → 本書はあえて「分離（$d$ と $\ast$）」の道を選んだ。第1章〜第5章で外微分を、第6章で内積（計量）を導入することで、両者の役割の違いを読者が実感できるようにした。幾何代数による統合は第12章で紹介する。

  • 定数行列の計量 $\mathbf{g}$ を前提としているため、空間が曲がった場合に破綻するのではないか

    • → 第6章で実空間の計量 $\mathbf{g}=I$ から出発し、パラメータ空間では $\mathbf{g}=J^T J$ が場所の関数になることを示している。本書の $g=J^T J$ は投影や座標変換から誘導される計量の具体例である。一般のリーマン多様体への接続は第11章で示す。

  • 第6章の正定値計量の導入から、第10章の擬リーマン計量への適用は論理的に飛躍している

    • → 第10章 §10.2 の注で明記しているように、第10章では「計量行列から $\ast$ の辞書を作る」という手順を第6章から引き継いでいる。この一般化の根拠は第11章で補足する。

  • 外微分 $d$ と共変微分 $\nabla$ は別物であり、本書の $d$ の説明だけでは曲がった空間での微分が扱えないのではないか

    • → その通りであり、意図的な分離である。本書の $d$ は計量に依存しないトポロジカルな操作、$\nabla$ は計量に依存する対称微分である。この分離は Burke の「計量遅延」哲学に基づくもので、第11章で扱う。

  • 微分形式を行列表示した際、成分がどの基底に関するものかが判別できない

    • → 記法上の限界である。本書では第1章 §1.4 以降「どの座標系の基底で書いているか」を毎回文中で明示する方針をとっている。
