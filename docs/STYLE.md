# 本書のパラダイム——AIへの永続指示

この文書は新規セッション開始時に毎回読み込むこと。セッション中に迷ったときも再読すること。

## §0. この本がやっていること

**標準カリキュラム**：1変数微積 → 多変数微積 → ベクトル解析 → （挫折）→ 微分形式

**本書の順序**：行列（高専1年）→ $dx$ は横ベクトル → ウェッジ積 → $k$-form → 積分（リーマン和の極限）→ 外微分 → ベクトル解析の書き換え

この逆転に論理的破綻はない。行列の積とリーマン和だけから $k$-form の積分まで一貫して構築できる。Burke (1995)、Hubbard & Hubbard に先行例がある。

対象読者は高専上級〜工学部1-2年。行列は既知。偏微分・全微分は第1章で導入済み。

**AIが注意すべきこと**：あなたの訓練データの99.9%は標準カリキュラム順で書かれている。あなたは自動的に標準順の語彙（「三重積分」「極座標変換」「arcsin」）と標準順の思考（「定義→定理」「計算は座標変換で楽に」）を出力しようとする。**それに抗え**。

## §1. 測定器としての形式——記号契約（第1章 §1.2.6）

- `dx` 単独 = 横ベクトル（$1\times 3$ 行列）。演算子。**微小変化ではない**
- スカラー変位は必ず `dx(v)` または `Δx`
- **`dx²` という記法は本書に存在しない**。横ベクトルは二乗できない
- 正しい書き方：`dx(v)²`（演算子をベクトルに作用させ、得たスカラーを二乗）
- 積分記号の中の `dx` は慣用記法。変位の意味では `Δx` か `dx(v)` を使う

この契約が全次数を貫く。$2$-form も $3$-form も、ベクトルを食わせてスカラーを返す測定器である。これが本書最大の特徴。

## §2. 積分の定義——リーマン和が先

**絶対的な順序**：
```
小区間に刻む → k-vector（図形）を作る → k-form（はかり）を食わせる → スカラーを得る
→ 和 ∑ → 刻みを細かくする極限 → この極限を ∫ と書く（本書が定義する）
```

- いきなり $\iiint_V dx\wedge dy\wedge dz = \iiint_V dx\,dy\,dz$ と書いてはいけない
- $\iiint$, $\iint$ は本書が初出として定義する記号。高校で習った前提にしない
- **本書は「三重積分」「二重積分」「重積分」という概念を導入しない**
- `∭ f dx dy dz`（wedge なし）とは決して書かない
- 逐次積分は「和の順序の整理」として説明する。カッコで計算順序を必ず明示する
- `dx, dy, dz` が逐次積分に並ぶときは「∧ の省略ではなく和の整理の結果である」と必ず説明する

**対象読者へのシグナル**：「高校以来おなじみの」「大学初年次で学ぶ」等のフレーズは積極的に使う。これは読者への道標であり、知っていれば読み飛ばせるというシグナルである。ただし、これらのフレーズを**説明の代わり**にしてはいけない。シグナルの直後で本書の言葉による定義または説明を必ず行う。

## §3. 計算の哲学——泥臭く、愚直に

- 極座標・球座標・円柱座標を「計算の逃げ道」として使わない
- 直接 $x,y,z$ のまま積分範囲を書き下し、逐次積分を実行する
- 泥臭さ自体が「微分形式は特別な座標系なしで測れる」ことの証明である
- arcsin は高校で習わない。`y = a sin t` の置換積分で回避する
- 極座標は第1章 §1.5 で導入済み。円柱座標 $(r,\theta,z)$ は既知としてよい
- 球座標 $(\rho,\theta,\phi)$ は第1章では未導入。§3.3 で必要なときは $(x,y)$ をパラメータとするグラフ表示で回避する

## §4. 引き戻しと計量——概念の導入順序

- **引き戻し** = 連鎖律による測定器の焼き直し。第1章 §1.5 の $dx = \cos\theta\,dr - r\sin\theta\,d\theta$ が原型
- 引き戻しの前に「二つのデカルト座標の対比」を必ず行う（元の世界 vs パラメータの世界）
- **計量は第5章まで正式導入しない**。それ以前は「成分の二乗和の平方根」「長さや大きさを取り出す追加の規則」という言い方で伏線を張る
- **ヤコビアンという語は §3.6.8 で導入するまで使わない**。それ以前は「グリッドの比率」または「体積の伸び縮み率」
- **ホッジ・スター $\ast$ は第5章で定義するまで計算に使わない**。第5章以前のロードマップでは「後で導入する辞書」「後で出てくる対称性」程度の非操作的な伏線は許すが、$\ast(dx)=dy\wedge dz$ のような具体式は書かない
- **外微分 $d$ は第4章で導入するまで使わない**

未定義の概念は、読者の見通しを助けるロードマップとして名前を出してよい場合がある。ただし、次を守る：

- 未定義概念を計算規則として使わない
- 未定義概念の具体式を書かない
- 「まだ使っていない」という否定文で概念を紹介しない
- 名前を出すときは「後で導入する」「ここでは使わない」と明示し、本文理解に依存させない

## §5. 論理的一貫性——よくある失敗パターンと禁止例

| 間違い | なぜ間違いか | 正しい書き方 |
|---|---|---|
| 「弧長は本書の形式的な枠組みでは扱えない」 | 誤り。弧長は計量由来の線素 $ds$ を積分して扱える | 「$ds$ は $dx,dy,dz$ の線形結合としての $1$-form ではない。計量由来の線素として第5章で正式に扱う」 |
| `dx² + dy²` | 横ベクトルを二乗している。§1違反 | `dx(v)² + dy(v)²` |
| 「$\sqrt{dx^2+dy^2}$ と略記する」 | 記号契約の崩壊を追認している | `ds(v) = √(dx(v)² + dy(v)²)` と定義する |
| 「球座標を使えば簡単」 | 計算の逃げ | $x,y,z$ のまま愚直に積分範囲を書く |
| 「三重積分の変数変換公式」 | 本書にない概念を参照している | 「$3$-form の積分を別の座標で計算し直す規則」 |
| 「高校以来おなじみの三重積分である」 | シグナルではなく説明の代わりにしている | シグナルに使ったあと、本書の言葉で定義し直す |
| リーマン和なしでいきなり $\int$ | §2違反 | 必ず $\sum$ → 極限 → $\int$ の順 |
| 未定義の概念を否定文で言及（「球座標も使っていない」） | 未定義の語を紹介している | 肯定的に「$x,y,z$ のまま計算した」とのみ書く |
