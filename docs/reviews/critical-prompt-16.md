# Critical Prompt 16 検証結果：係数2・符号・向き

## 妥当性

Prompt 16 は妥当。Issue 作成前に必須の横断検算である。

## 検証結果

現時点で安全と見てよいもの：

- `dx∧dy`, `dy∧dz`, `dz∧dx` の右手系順序。
- Hodge star の 3D Euclidean 辞書。
- `curl` と `div` の標準右手系符号。
- 円柱・球座標の主要な発散・回転公式。
- フロベニウス積の `1/2` は、反対称行列の重複成分を二重計数しないための規約として筋が通っている。

不整合候補：

- 第10章の電磁場 `F` は、反対称行列の符号と基底 2-form 表示の符号が食い違って見える。
- `∂(∂M)=∅` は符号付き相殺を「空」と言っているため、向きの説明としては弱い。
- 第5章 Stokes では曲面の向きと境界の誘導向きの明示が薄い。

## Issue 化

採用候補：

1. Maxwell 章の符号規約検算。
2. `∂^2=0` を「空」ではなく「向き付きでゼロ」と書く。
3. Stokes の誘導向きの注を追加する。
