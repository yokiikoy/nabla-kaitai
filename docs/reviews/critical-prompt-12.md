# Critical Prompt 12 検証結果：標準微分幾何・多様体論への接続

## 対象補正

元プロンプトは第11章を対象にしており、現行原稿でも第11章は多様体・標準微分幾何への接続章である。対象は一致している。

## 好意的再構成

第11章は、前半の行列表示を標準理論へ接続する役割をかなり明確に果たしている。

| 前半の記法 | 第11章での回収 |
|---|---|
| `dx = (1 0 0)` | 各点の余接基底 $dx^i|_p$ の成分表示 |
| 横ベクトル×縦ベクトル | 1-form と接ベクトルの双対ペアリング |
| 2-form の反対称行列 | 交代多重線形写像の成分表示 |
| pullback | $(f^*\omega)_p(v_1,\ldots,v_k)=\omega_{f(p)}(df_pv_1,\ldots,df_pv_k)$ |
| 外微分 $d$ | 計量不要な $\Omega^k(M)\to\Omega^{k+1}(M)$ |
| Hodge star | 計量と向きに依存する $\Omega^k(M)\to\Omega^{n-k}(M)$ |

特に、`dx` の点依存を第11章で明示している点は、前半の教育的略記をきちんと回収している。

## 問題候補

### 1. 第9章の曲線座標計量を「場所に依存しない定数行列」と書いている

該当箇所：

- `manuscript/ja/ch11/ch11.md:52`

本文は「第6章で計量を導入し、第9章で `g` から `*` の辞書を作る手順を練習した。いずれも `g` は場所に依存しない定数行列だった」と述べている。

しかし第9章の円柱座標では

$$
g=\mathrm{diag}(1,r^2,1)
$$

球座標では

$$
g=\mathrm{diag}(1,\rho^2,\rho^2\sin^2\theta)
$$

であり、明らかに座標に依存する。ここは「空間は平坦だが、座標表示の計量成分は場所に依存した」と書くべきである。第11章自身も `g_ij(x)` の場所依存と曲率は別物だと説明しているため、現在の一文は内部矛盾になっている。

Issue 化判定：採用候補。重大度は中〜高。

### 2. 引き戻しの章参照が旧構成のまま

該当箇所：

- `manuscript/ja/ch11/ch11.md:122`
- `manuscript/ja/ch11/ch11.md:179`

第11章は「本書第3章で座標変換のヤコビアンとして計算した引き戻し」と書いているが、現行原稿で pullback は第4章である。これは参照ずれ一括 Issue に統合する。

Issue 化判定：採用候補。ただし一括参照修正へ統合。

### 3. 「統一 Stokes の定理」を第8章としている箇所は、初出との関係を整理したい

該当箇所：

- `manuscript/ja/ch11/ch11.md:138`
- `manuscript/ja/ch11/ch11.md:183`

一般 Stokes 型の式は第5章 §5.9 で統合され、第8章ではベクトル解析記法からの翻訳として再登場している。第11章で「第8章で出会った」とだけ書くと、初出がずれる。

修正方針：

- 「第5章で統一し、第8章で $\nabla$ 表記から再確認した」と書く。

Issue 化判定：採用候補。ただし一括参照修正へ統合。

### 4. `*` の一般理論は良いが、擬リーマン計量の符号規約は第10章と連携が必要

該当箇所：

- `manuscript/ja/ch11/ch11.md:148`
- `manuscript/ja/ch11/ch11.md:152`
- `manuscript/ja/ch11/ch11.md:154`

第11章は、擬リーマン計量では $\sqrt{|\det g|}$ や符号規約に注意が必要と述べており、これは妥当である。ただし第10章では Minkowski Hodge star を具体的に使っているため、第10章側の符号規約検算と連動させる必要がある。

Issue 化判定：単独では保留。Prompt 11 の Maxwell 符号 Issue に統合。

## 採用しない候補

### 多様体論の基本定義

チャート、アトラス、接空間、余接空間、外微分、Hodge star、接続、曲率の説明は、入門的な道標として大きな破綻はない。証明の章ではなく「先に進むための地図」として書かれているため、細部の省略は許容できる。

### `dx = (1 0 0)` の回収不足

第11章は `dx^i|_p` と余接空間 $T_p^*M$ を明示しており、前半の略記をかなり明確に救済している。この点は Issue 化しない。

## 今回の結論

Prompt 12 は妥当。Issue 候補は次の二件。

1. 第11章冒頭の「第9章の `g` は定数行列だった」を修正し、平坦性と座標依存計量を区別する。
2. 第11章内の旧章参照を現行構成へ修正する。

Maxwell/Hodge star の符号規約は、第10章の符号検算 Issue に統合する。
