# Critical Prompt 15 検証結果：全体横断・等号監査

## 妥当性

Prompt 15 は妥当。ただし `dx=(1 0 0)` 単独は、第11章でかなり救済されているため、強い Issue にはしない。

## 等号の分類

| 等号 | 分類 | 判定 |
|---|---|---|
| `dx=(1 0 0)` | 固定座標の成分表示 | 第11章で回収済み。単独 Issue 不採用 |
| `2-form = 反対称行列` | 成分表示 | 第2章・付録で規約があるため救済可能 |
| `grad f = df` | 計量同一視を省略 | Issue 候補 |
| `rot F = *dω` | 計量同一視を省略 | Issue 候補 |
| `ds(v)=sqrt(...)` を 1-form | 厳密には不適切 | Issue 候補 |
| `F` の反対称行列 = 基底 2-form 表示 | 符号規約の等号 | 第10章で不整合疑い。Issue 候補 |

## 結論

等号監査から直接強い Issue になるのは次の三つ。

1. 第3章 `ds` の型誤り。
2. `grad/rot/div` の `♭/♯` 省略。
3. 第10章 Maxwell の行列表示と 2-form 表示の符号整合性。
