# Critical Prompt 25 検証結果：LLM用批判的読解メタプロンプト

## 妥当性

Prompt 25 は妥当。ただしこれは原稿の Issue を作るためのプロンプトではなく、今後のレビュー実行時に使うメタプロンプトである。

## 採用方針

今後の監査・Issue 本文作成では、Prompt 25 の規則を次のように使う。

- 著者の自己限定だけで正当化済みとしない。
- すべての等号を「対象」「表示」「同一視」「略記」に分類する。
- `dx`, `df`, `d`, `*`, `∇`, grad/curl/div では必ず型を確認する。
- 曲線座標では、pullback、計量、Hodge star、正規直交成分を分ける。
- 最終評価では、著者の意図ではなく、読者が本文だけで安全に読めるかを基準にする。

## 結論

Prompt 25 は、Issue 作成時のレビュールールとして採用する。単独 Issue にはしない。
