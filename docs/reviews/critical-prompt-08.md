# Critical Prompt 08 検証結果：grad・rot・div・ナブラ記号

## 対象補正

元プロンプトは第7章を対象としており、現行原稿でも第7章はナブラ記法の章である。ただし第7章は意図的に `d`, `*`, `∧` を使わず、標準ベクトル解析を一度そのまま提示する章として書かれている。したがって、Prompt 08 の「微分形式で再構成できているか」は、第7章単体ではなく、第6章・第8章への接続を含めて評価する。

## 第7章の好意的再構成

第7章は、ナブラを

$$
\nabla=
\begin{pmatrix}
\partial_x\\
\partial_y\\
\partial_z
\end{pmatrix}
$$

という形式的な微分演算子ベクトルとして導入し、標準ベクトル解析の演算を次のように定義している。

| 演算 | 第7章の定義 | 型 |
|---|---|---|
| grad | $\nabla f$ | scalar field → vector field |
| div | $\nabla\cdot F$ | vector field → scalar field |
| rot/curl | $\nabla\times F$ | vector field → vector field |
| Laplacian | $\nabla\cdot\nabla f$ | scalar field → scalar field |

さらに `rot(grad f)=0` と `div(rot F)=0` を混合偏微分の交換から示し、積分定理として Stokes・Gauss・Green を提示している。これはベクトル解析の章として妥当である。

## 標準理論との対応表

本書の微分形式側で正確に書くなら、3次元ユークリッド右手系では次の対応になる。

| ベクトル解析 | 微分形式側 |
|---|---|
| $\nabla f$ | $(df)^\sharp$ |
| $\nabla\times X$ | $(\ast d X^\flat)^\sharp$ |
| $\nabla\cdot X$ | $\ast d\ast X^\flat$ |
| $\nabla\times\nabla f=0$ | $\ast d(df)=\ast d^2f=0$ の `sharp` 版 |
| $\nabla\cdot(\nabla\times X)=0$ | $\ast d\ast(\ast dX^\flat)=\ast d^2X^\flat=0$ |

第7章自体は `♭/♯` を使わず、矢印としてのベクトル解析を提示する章なので、ここで未導入なのは構成上は許容できる。ただし第6章・第8章で対応表を完成させる際には、計量同一視を明示したほうがよい。

## 問題候補

### 1. `grad=d`, `rot=*d`, `div=*d*` の参照先がずれている

該当箇所：

- `manuscript/ja/ch07/ch07.md:47`
- `manuscript/ja/ch07/ch07.md:147`
- `manuscript/ja/ch07/ch07.md:434`

第7章では「§5.5 で `d` と `*` の組み合わせとして登場」と書いているが、現行構成ではこの対応は第6章 §6.5 にある。`§5.5` は一般の 1-form の外微分の節であり、Hodge star はまだ導入されていない。

Issue 化判定：採用候補。参照ずれ一括 Issue に統合する。

### 2. `∇` を「ベクトル」と呼ぶ箇所は形式的演算子であることを強めたい

該当箇所：

- `manuscript/ja/ch07/ch07.md:125`
- `manuscript/ja/ch07/ch07.md:133`

第7章は「$\nabla$ は『ベクトル』だが、その成分は数ではなく微分演算子」と説明しており、最低限の注意は入っている。より厳密には、$\nabla$ はベクトル場ではなく、座標表示された形式的な微分演算子である。

Issue 化判定：単独では弱い。本文の注がすでにあるため、採用しない。ただし `grad/rot/div` 翻訳表の補足で「形式的演算子」と明記するのは有用。

### 3. `grad f` の縦ベクトル説明が `df` との関係を絵の違いとして説明している

該当箇所：

- `manuscript/ja/ch07/ch07.md:145`
- `manuscript/ja/ch07/ch07.md:147`

第7章は、$\nabla f$ と $df$ の違いを「空間に矢印を立てる見方」と「form が変化している見方」として説明している。しかし標準的には、違いは見方だけではなく、計量同型

$$
\nabla f=(df)^\sharp
$$

の有無である。第7章の説明は読者にはやさしいが、第6章で計量を導入した後としては、計量による `sharp` を一文入れたほうがよい。

Issue 化判定：採用候補。ただし Prompt 07 の `grad/rot/div 型整理` Issue に統合する。

### 4. `rot(grad)=0`, `div(rot)=0` の説明が第7章単独では `d^2=0` と接続していない

該当箇所：

- `manuscript/ja/ch07/ch07.md:273`
- `manuscript/ja/ch07/ch07.md:287`
- `manuscript/ja/ch07/ch07.md:301`

第7章は、意図的に混合偏微分の交換だけで恒等式を示している。これはベクトル解析章としては正しい。ただし本書全体の中心主張としては、第8章側で「これは `d^2=0` の別表現」と再接続する必要がある。

Issue 化判定：第7章単体では採用しない。第8章で接続が不足していれば採用。

### 5. 「Maxwell 方程式には本来 `*` などいらない」は過大表現になりうる

該当箇所：

- `manuscript/ja/ch07/ch07.md:378`

「$d$ と $\wedge$ だけで編まれた世界では、問題なくマクスウェル方程式を構成できる」という表現は注意が必要である。微分形式で Maxwell 方程式を書くと、幾何学的な閉形式方程式は $dF=0$ で書けるが、真空中で $F$ と電流を結ぶ構成や構成方程式には計量依存の Hodge star が現れるのが標準的である。

Issue 化判定：保留。Prompt 11/12 の Maxwell・物理応用監査で扱う。

## 符号・計量・Hodge star の整合性

第7章のベクトル解析公式そのものは標準的な右手系の符号と一致している。

- `rot F` の成分順は標準的な $\nabla\times F$。
- `div F` はヤコビ行列のトレース。
- Stokes の向きは右ねじ関係として説明されている。
- Gauss は外向き法線として説明されている。

現時点で符号 Issue は見つからない。

## 今回の結論

Prompt 08 は妥当。ただし第7章は「いったんベクトル解析をそのまま見せる章」なので、Issue 化は次に絞る。

1. 第7章の `§5.5` 参照を、現行の第6章 §6.5 へ直す。
2. `grad/rot/div` の微分形式対応では、`♭/♯` に相当する計量同一視を明示する。

Maxwell に関する強い言い方は、後続の物理応用監査まで保留する。
