## 1. 第2章の好意的再構成

第2章は、第1章で導入した `dx, dy, dz` を部品として、2つのベクトルを食べる交代双線形形式、3つのベクトルを食べる交代3重線形形式を、行列・テンソル配列として構成する章である。

標準理論に翻訳すると、次の流れになる。

- 2-form は、固定した標準基底に関する交代双線形形式である。
- `dx wedge dy` は `dx tensor dy - dy tensor dx` として定義される。
- その成分表示は反対称行列になる。
- `dy wedge dz`, `dz wedge dx`, `dx wedge dy` が `R^3` の基底2-form として使われる。
- 3-form `dx wedge dy wedge dz` は、行列式として3本のベクトルを評価する体積形式である。
- 付録Aでは、Levi-Civita 記号に相当する3階反対称テンソルを、3枚の反対称行列として表示している。

本文根拠:

- 2-form と 3-form を「ベクトルを食べる測定器」として導入する: `manuscript/ja/ch02/ch02.md:51`
- 面積測定器に双線形性・交代性・規格化を課す: `manuscript/ja/ch02/ch02.md:95`
- 2-form を反対称行列と呼ぶ: `manuscript/ja/ch02/ch02.md:199`
- wedge を `dx tensor dy - dy tensor dx` と定義する: `manuscript/ja/ch02/ch02.md:303`
- 3つの基底2-form を構成する: `manuscript/ja/ch02/ch02.md:318`

## 3. wedge の係数・符号・正規化

第2章の wedge 定義は、少なくとも1-form同士については

```text
dx wedge dy = dx tensor dy - dy tensor dx
```

であり、`1/2` は入らない。この規約では

```text
(dx wedge dy)(v1, v2) = x1 y2 - y1 x2
```

となり、本文の計算と整合する。2-form を反対称行列として `u^T M v` で評価する場合も、`M_xy = 1`, `M_yx = -1` の行列を使うため、同じ値が得られる。

現時点では、係数2の破綻は見つからない。ただし、第6章の Hodge star やフロベニウス内積で反対称行列同士の内積を取ると、行列成分を全成分で数えるか、独立成分だけで数えるかによって係数2が問題になる可能性がある。これは Prompt 7/16 へ引き継ぐ。
