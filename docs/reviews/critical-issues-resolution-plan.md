Issue 番号順ではなく、本文構造・型の土台・計量依存性・Maxwell 符号規約の順に処理する。

- 対象リポジトリ: `yokiikoy/nabla-kaitai`

  - `docs/reviews/critical-prompt-01.md` 〜 `docs/reviews/critical-prompt-25.md`

## Phase 1: 参照ずれ・低リスク整備

対象 Issue:

- #30 全体: 章番号・節番号の参照ずれを一括修正する
- #28 第11章: 第9章の計量を「定数行列」とする記述を修正する
- #29 第12章: 「真のナブラ」「究極のマクスウェル方程式」などの過大表現を弱める

作業内容:

1. 本文全体の `第N章`, `§N.M`, `第N章 §M.K` 型参照を棚卸しする。
2. 現行の章構成に合わせて参照先を修正する。
3. 第11章の「第9章の `g` は定数行列だった」を、平坦性と座標依存計量を区別する文に直す。
4. 第12章の「真の」「究極」など、展望章として強すぎる表現を弱める。

注意:

- 参照修正は内容修正と混ぜすぎない。
- 節番号が今後変わりやすい箇所では、可能なら章名・節名を併記する。

想定 PR:

- `fix/reference-drift-and-scope-wording`

## Phase 2: 型の誤りと Stokes 周辺

対象 Issue:

- #16 第3章: `ds` を 1-form と呼ぶ箇所を計量的線素として修正する
- #17 第3章: 一般の 1-form を exact form と誤読されない形に修正する
- #19 第5章: `d` と積分を片側逆として説明する注を型安全にする
- #20 第5章: `境界の境界は空` を向き付き境界としてゼロに修正する
- #21 第5章: Stokes の誘導向きと局所化の仮定を補う

作業内容:

1. 第3章の `ds(v)=sqrt(...)` を、1-form ではなく計量から得る線素・長さ要素として書き直す。
2. 第3章の一般 1-form を `P dx + Q dy + R dz` で導入し、`df` を特殊例にする。
3. 第5章の `d` と積分の「片側逆」説明を削除または弱め、基本定理・Stokes 型公式として説明する。
4. `partial(partial M)=empty` を `partial^2 M=0` または「向き付き境界としてゼロ」に修正する。
5. Stokes の曲面向きと境界の誘導向き、局所化推論の滑らかさ・任意小領域の仮定を補う。

注意:

- `ds` の修正は第6章の計量導入と矛盾しないようにつなぐ。
- 一般 1-form の修正は第5章の `P,Q,R` 説明と整合させる。

想定 PR:

- `fix/form-types-and-stokes-assumptions`

## Phase 3: Pullback・計量・曲線座標

対象 Issue:

- #18 第4章: 一般 pullback 定義を有限差分記号から偏微分・ヤコビ行列へ修正する
- #22 第6〜8章: grad/rot/div の翻訳表に計量同一視を明記する
- #23 第9章: 曲線座標公式の射程を直交曲線座標中心に限定する
- #24 第9章: 曲線座標での正規直交成分と form 係数の規約を固定する
- #25 第9章: 円柱・球座標の座標特異点と定義域を明示する

作業内容:

1. 第4章の有限マス目説明は残し、一般定義では偏微分・ヤコビ行列式を使う。
2. 第6〜8章の `grad/rot/div` 辞書を、形式としての型とベクトル解析としての型に分ける。
3. `flat/sharp` 記号を導入するか、導入しない場合も「ユークリッド計量による同一視を省略している」と明記する。
4. 第9章の「任意の座標系」を直交曲線座標中心の記述に限定する。
5. 円柱座標・球座標で、正規直交成分と form 係数の対応表を追加する。
6. `r=0`, `rho=0`, `theta=0,pi` などの座標特異点と通常の座標パッチを導入時に明記する。

注意:

- #22 と #24 は強く関連するため、同じ PR で扱う。
- 非直交座標の一般 Hodge star 公式までは深入りせず、射程限定に留める。

想定 PR:

- `fix/pullback-metric-coordinate-dictionaries`

## Phase 4: Maxwell 章の符号・単位検算

対象 Issue:

- #26 第10章: Maxwell の反対称行列表示と 2-form 表示の符号を検算する
- #27 第10章: 正規化済みの B, t, J, current form の意味を表で固定する

作業内容:

1. 第2章の 2-form 反対称行列表示規約を再確認する。
2. 第10章の `F` 行列、基底 2-form 表示、`F=-dA` の符号を一貫検算する。
3. 必要なら `F` の行列表示または基底 2-form 表示を修正する。

5. `mathcal J` と標準 4-current の係数差を明示する。
6. 第12章の源あり Maxwell の 3D パウリ形式にも、同じ正規化のもとでの概略式であることを注記する。

注意:

- この Phase は数式リスクが最も高い。単独 PR とし、検算ログを PR 本文かレビュー文書に残す。
- 符号規約の修正は第12章にも波及しうる。
