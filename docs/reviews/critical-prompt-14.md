# Critical Prompt 14 検証結果：付録・予防線・想定反論

## 妥当性

Prompt 14 は妥当。章単位ではなく、本文注・付録・射程限定の横断監査として実行すべきである。

## 検証結果

本書には「教育的略記」「後章で回収」「本線から外れる」「標準理論ではこうなる」という予防線が多い。多くは有効だが、すべてを免責するわけではない。

有効に働いている例：

- 第11章で `dx=(1 0 0)` を `dx^i|_p` の成分表示として回収している。
- 第6章・第11章で `d` は計量非依存、`*` は計量依存と明示している。
- 第12章冒頭で、幾何代数章は本線外のおまけだと限定している。

不十分な例：

- 第3章の `ds` を 1-form と呼ぶ箇所は、第6章への伏線では救済できない。`ds` は線形な 1-form ではないため、本文中で修正が必要。
- `grad=d`, `rot=*d` などは、第6〜8章の予防線だけでは `♭/♯` の省略を十分に明示できていない。
- 「任意の座標系」は、第9章の直交曲線座標実例だけでは広すぎる。
- 第12章の「真の」「究極」は、おまけ宣言があっても定理的主張に見えやすい。

## Issue 化

Prompt 14 自体は直接 Issue 化しない。以下の既存候補を補強する横断根拠として使う。

1. `ds` を 1-form と呼ぶ箇所の修正。
2. `grad/rot/div` 翻訳表への `♭/♯` 明記。
3. 第9章の射程を直交曲線座標中心に限定。
4. 第12章の過大表現調整。
