# Critical Prompt 13 検証結果：結論・射程・主張の過大化

## 対象補正

元プロンプトは第12章を対象としており、現行原稿でも第12章は最終章である。ただし第12章は通常の結論章ではなく、パウリ行列・ディラック演算子・幾何代数への「おまけ」章として書かれている。

## 好意的再構成

第12章は、第8章までで完成した `∇` の解体

$$
\mathrm{grad},\mathrm{rot},\mathrm{div}
\quad\leadsto\quad
d,\ast
$$

を、今度はパウリ行列・クリフォード代数的な積の中で再統合する章である。章冒頭で「完全なおまけ」「厳密な幾何代数の教科書ではない」と明示しており、本文の本線から外れた展望として読む限りは有効である。

## 問題候補

### 1. 第12章内の節参照が誤っている

該当箇所：

- `manuscript/ja/ch12/ch12.md:190`
- `manuscript/ja/ch12/ch12.md:201`
- `manuscript/ja/ch12/ch12.md:294`

`11.2.2` や `11.2.1` の積の公式を参照しているが、該当するパウリ行列の積は第12章 §12.2.1/§12.2.2 である。これは参照ずれ一括 Issue に含める。

Issue 化判定：採用候補。

### 2. `真のナブラ`・`究極のマクスウェル方程式` は展望としてはよいが、定理的主張に見える

該当箇所：

- `manuscript/ja/ch12/ch12.md:25`
- `manuscript/ja/ch12/ch12.md:296`
- `manuscript/ja/ch12/ch12.md:304`

章冒頭で「おまけ」と限定しているため、完全な射程逸脱ではない。しかし「真のナブラ」「究極のマクスウェル方程式」は、厳密な幾何代数の定義・符号規約・単位系を省略した章としては強すぎる。

修正方針：

- 「本書が到達できる一つの統合的見方」程度に弱める。
- `究極` は本文ではなく比喩であることを明示するか、削除する。

Issue 化判定：採用候補。重大度は中。

### 3. 源あり Maxwell の 3D パウリ形式で、係数・単位・符号が省略されている

該当箇所：

- `manuscript/ja/ch12/ch12.md:274`
- `manuscript/ja/ch12/ch12.md:276`

真空では式の構造を見るだけでよいが、電流 $\mathbf{J}$ と電荷 $\rho$ がある場合に

$$
(D+\partial_t)F=\rho+\mathbf{J}\cdot\sigma
$$

と置く、という説明は係数・単位・符号規約を大幅に省略している。第10章では $B$, $t$, $\mathcal{J}$ を正規化していたため、第12章でも同じ正規化のもとでの概略式であることを明記すべきである。

Issue 化判定：採用候補。第10章の正規化 Issue と統合可能。

### 4. `D ~ d + δ` の説明は符号を保留しているため、中心主張の根拠には使いすぎない

該当箇所：

- `manuscript/ja/ch12/ch12.md:218`

本文は「符号規約を別にすれば」「厳密な符号には立ち入らず」と明示している。これは予防線として正しい。ただしこの保留を置いたまま、後段で「統合」「真のナブラ」を強く言い切ると、読者には証明済みに見える可能性がある。

Issue 化判定：2 の表現調整に含める。

## 採用しない候補

### `F+i*F` の 4次元依存性

第12章は、$F+i*F$ が 4 次元で `*` が 2-form を 2-form に写すことに依存していると明示している。ここは過大化していない。

### パウリ行列積による内積・外積の分解

計算自体は明示されており、標準的な

$$
(\sigma\cdot v)(\sigma\cdot w)=v\cdot w\,I+i\sigma\cdot(v\times w)
$$

に一致する。ここは Issue 化しない。

## 今回の結論

Prompt 13 は妥当。Issue 候補は次の三件。

1. 第12章内の `11.2.x` 参照を `12.2.x` へ直す。
2. 「真の」「究極」など、展望章として強すぎる表現を弱める。
3. 源あり Maxwell の 3D パウリ形式に、正規化・単位・符号規約の注を追加する。
