# Critical Prompt 17 検証結果：計量依存性

## 妥当性

Prompt 17 は妥当。本書全体の最重要横断監査である。

## 分類

計量非依存：

- 1-form の接ベクトルへの作用
- wedge 積
- pullback
- 外微分 `d`
- `d^2=0`
- Stokes 型定理の形式的構造

計量依存：

- 長さ、角度、内積
- `ds`
- Hodge star
- 1-form とベクトル場の同一視
- 2-form とベクトル場の対応
- grad/curl/div のベクトル解析表示
- 曲線座標の正規直交成分への変換

## 問題候補

1. `ds` は計量依存の線素であり、1-form ではない。
2. `grad=df`, `rot=*d`, `div=*d*` は、形式としての出力とベクトル解析としての出力を分ける必要がある。
3. 第9章は直交曲線座標の計量処理としてはよいが、非直交座標まで射程を広げるなら説明不足。
4. 第11章冒頭の「第9章の `g` は定数」は誤り。

## 結論

Prompt 17 は、Issue 候補をかなり強く裏づける。特に `ds` と `♭/♯` は優先度が高い。
