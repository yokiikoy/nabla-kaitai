## 1. 第1章の好意的再構成

第1章は、標準デカルト座標を固定した `R^3` において、余ベクトル・1-form を行ベクトルとして表示する導入である。

最も好意的に読むなら、`dx = (1 0 0)` は「`dx_p` という余接空間の基底1-form の、標準デカルト座標における成分表示を、初学者向けの記号契約として等号で書く」という主張である。本文もこの点をかなり明示しており、`dx` を微小変位ではなく、変位ベクトルから `x` 成分を抜き出す線形写像として扱う。

本文根拠:

- `dx` を `1 x 3` 行列として定義する: `manuscript/ja/ch01/ch01.md:109`
- それが入力ベクトルから `x` 成分を抜き出す線形演算子の行列表現だと説明する: `manuscript/ja/ch01/ch01.md:116`
- 等号ではなく表示対応として読むのが慎重だと明記する: `manuscript/ja/ch01/ch01.md:125`
- ただし本文では等号を採用すると宣言する: `manuscript/ja/ch01/ch01.md:131`
- `dx` を微小幅に使わない記号契約を置く: `manuscript/ja/ch01/ch01.md:197`
- 第11章で `dx^1|_p` の成分表示として回収する: `manuscript/ja/ch11/ch11.md:108`

## 2. `dx = (1 0 0)` の分類

| 等号 | 分類 | 評価 |
|---|---|---|
| `dx = (1 0 0)` | 固定座標・固定基底における表示の等号を、本文契約として対象の等号のように書く | 本文内で明示的に限定されており、局所的には救済可能 |
| `dy = (0 1 0)`, `dz = (0 0 1)` | 同上 | `dx` と同じ契約を適用する形で十分説明されている |
| `df = f'(x) dx = (f'(x) 0 0)` | 1-form の成分表示 | `df(v)` が変化量の一次主項であることが明示され、誤読対策は強い |

第1章だけを見る限り、`dx = (1 0 0)` を無自覚な誤用とは分類しない。むしろ、本文は危険性を知ったうえで教育的契約として採用している。

ただし、標準数学としての厳密な書き換えは次の形になる。

```text
各点 p において dx_p in T_p^* R^3 は、標準座標基底に対する双対基底の第1成分であり、
その成分表示は (1 0 0) である。
```

## 3. `dx, dy, dz` の属する空間

第1章本文では、`dx, dy, dz` は次のように扱われる。

| 記号 | 第1章での扱い | 標準的な読み |
|---|---|---|
| `dx` | `R^3` の変位ベクトルから `x` 成分を抜く `1 x 3` 行列 | 標準デカルト座標での `dx_p in T_p^*R^3` の成分表示 |
| `dy` | `y` 成分を抜く `1 x 3` 行列 | `dy_p` の成分表示 |
| `dz` | `z` 成分を抜く `1 x 3` 行列 | `dz_p` の成分表示 |
| `dr, dtheta, dz` | パラメータ空間の成分を抜く横ベクトル | パラメータ空間側の余接基底 |

第1章は「どの座標系に載っているか」を説明しようとしている。特に `dr`, `dtheta` について、見た目は同じでも載っている座標系が違うと明記する点は有効である。

## 4. 点依存性の管理

第1章では、点依存性 `p` は基本的に省略される。これは初学者向けの成分表示という方針とは整合する。

一方、円柱座標表示では `dx` の成分が `r, theta` に依存するため、点で評価してから作用させる必要がある。本文は演習で「点 `P` における行列 `dx`」と書き、評価後であることを明示している。

本文根拠:

- 座標を替えると `dx` の成分表示が変わる: `manuscript/ja/ch01/ch01.md:400`
- 対象そのものは不変でも成分表示が変わると述べる: `manuscript/ja/ch01/ch01.md:408`
- 点 `P` の座標で評価した後を指すと明記する: `manuscript/ja/ch01/ch01.md:477`
- 第11章で点依存性を回収する: `manuscript/ja/ch11/ch11.md:108`

評価: 点依存性の完全な管理は第11章まで遅延されるが、第1章の範囲では実害を避ける注記がある。危険度は「中」。

## 5. `df` の分類

| 表現 | 本文上の分類 | 標準理論での分類 | 評価 |
|---|---|---|---|
| `df = f'(x) dx` | 横ベクトル、演算子 | 1-form、各点の線形写像 | 妥当 |
| `df(v)` | 一次近似としての変化量 | `df_p(v)` | 妥当 |
| `df` 単体 | 変化量ではない装置 | 余接ベクトル場または1-form | 誤読対策あり |
| 3変数の `df` | 偏微分係数を並べた横ベクトル | 1-form の局所表示 | 妥当 |

本文は `df` と `df(v)` の区別をかなり強く書いており、ここは第1章の強い点である。

本文根拠:

- `df` を横ベクトルとして定義する: `manuscript/ja/ch01/ch01.md:232`
- `df` も `dx` も演算子であり単体では微小変化量ではないと述べる: `manuscript/ja/ch01/ch01.md:239`
- `df` それ自体は変化量ではないと明記する: `manuscript/ja/ch01/ch01.md:243`
- 3変数の `df` を横ベクトルとして定義する: `manuscript/ja/ch01/ch01.md:333`
- `df(v)` は一次主項であり `Delta f` そのものではないと述べる: `manuscript/ja/ch01/ch01.md:335`
