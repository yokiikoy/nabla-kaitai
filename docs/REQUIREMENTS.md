# 要件定義

## 1. 企画背景

### 1.1 目的

本書の本線の目的は**第I〜III部**にある。ベクトル解析の「計算はできるが腑に落ちない」層に対し、微分形式を「行列」という既知の道具から再構築することで、代数的な納得を提供する。第III部でベクトル解析挫折者の問題は解決する。

**第IV部とch11**は、本書に愛着を持った読者が卒業後に戻ってきて「なるほど」と更に好きになるためのものである。特にch11の「真のナブラ」（ディラック演算子）への到達は、本書のタイトルにかけたイースターエッグ的な仕掛けであり、初読で理解できなくても構わない。

### 1.2 表題

- 日本語: **ナブラ解体新書**
- サブタイトル: 行列表示の微分形式によるベクトル解析の抜け道
- 英語: **Unmasking Div Grad Curl: An Elementary Matrix Bypass via Exterior Forms**

## 2. ターゲットと4部構成

| 部 | 章 | 対象読者 | 目的 |
|---|---|---|---|

| **第II部** | ch04-06 | 学部3年程度、他書や講義でベクトル解析に触れたことはあるが腑に落ちていない人 | 微分形式によるベクトル解析の**ボトムアップな構築**。外微分・ホッジスターを積み上げ、ナブラの正体を解明する |

### 2.1 第I部の要件（ch01-03）

- 高校数学からの出発を徹底する（極限のε-δは使わない、行列の知識だけで進める）
- `dx` を行ベクトルとして定義し、1-form を「行列の掛け算」として感覚的に理解させる
- 線積分・面積分・体積分を「測定器の連続適用と集計」という統一的な枠組みで導入する
- 座標変換（引き戻し）は第3章で扱い、第1章ではデカルト座標に限定する

### 2.2 第II部の要件（ch04-06）— ボトムアップな構築

- 計量を「封印」し、第5章まで内積を導入しない（Burke の "put the metric later" 哲学）
- 外微分 $d$ を「次数を上げる唯一の操作」として、第1章の $df$ からの自然な拡張として動機づける
- ホッジ・スター $\ast$ の導入で初めて内積（計量）を「召喚」する — 劇的なタイミングとして設計する
- 読者は他書や講義でベクトル解析に触れたことはあるが、本書ではその知識に依存しない。既知の語彙（grad / rot / div）は登場させず、あくまで $d$ と $\ast$ の組み合わせとして後から「あれがこれだった」と名前がつく
- 読者体験は「ゼロから道具を組み立てている」感覚

### 2.3 第III部の要件（ch07-08）— 既習ベクトル解析の書き換え

- 第II部で構築した $d$ と $\ast$ の道具を使って、大学で（挫折しながらも）習ったベクトル解析の諸定理を**書き換える**
- ストークスの定理を $d$ と $\partial$ の双対性として提示し、ガウス・ストークス・グリーンの「大統一定理」を見せる — 「あの3つの定理は同じものだった」という納得を提供する
- 読者体験は「ああ、あの式はこういう意味だったのか」という**既習知識の再解釈**
- 第III部に入ると、読者が大学で（挫折しつつも）学んだベクトル解析の式が次々と登場し始める。これは**意図的なドラマ**であり、第II部の「ゼロから構築」の直後に「あっ、この式知ってる、これがこういう意味だったのか」と既習記憶が呼び起こされる体験を狙う。読者の前提にある既習知識に巧くフックすることで、再解釈の快感を最大化する

### 2.4 第IV部の要件（ch09-10）— おまけゾーン、展望のオーバービュー

- 他書でベクトル解析や相対論を学んだことがあることを前提とする
- **完結させる気はない**。あくまで「ここから先にはこんな世界がある」という展望を示す
- ch09: マクスウェル方程式を $dF = 0,\ d(\ast F) = \mu_0(\ast \mathcal{J})$ の2行で記述。相対論的マクスウェルや一般相対論と関係がありそうだぞ、というところを匂わせる
- ch10: これを本当に理解するには計量・多次元への拡張・多様体が必要だという**オーバービュー**を示す。深入りしない

### 2.5 最終章 ch11 — 真のナブラへの到達（未執筆・本書の締めくくり）

想定構成：

1. **§11.1 マクスウェル方程式を一式に** — 微分形式 $F$ に対して虚数単位 $i$ を導入し、$d + i\ast d$ のような形で陰に含まれる構造を見せる
2. **§11.2 異なる次数の足し算** — 0-form, 1-form, 2-form, 3-form を混ぜて足す世界（クリフォード代数の直観）を導入。ここから**パウリ行列**が自然に姿を現す
3. **§11.3 ディラック演算子と真のナブラ** — パウリ行列を用いた演算子が**ディラック演算子**そのものであり、これこそが「真のナブラ」であることを示す。$\nabla$ の解体から始まった旅が、$\partial\mkern-9mu/$ の発見で閉じる

本書全体の流れ：行列（第I部）→ 微分形式（第II-IV部）→ クリフォード代数／ディラック演算子（最終章）

**ch11 のみ未執筆**。これからドラフトを作成する。

## 7. 記法統一ルール（要項）

- `dx`, `dy`, `dz` は行ベクトルとして定義（第1章で導入）
- ウェッジ積は `\wedge` / $\wedge$、ホッジ・スターは `\ast` / $\ast$
- 外微分演算子は $d$（立体）、ベクトルは太字（`\mathbf{}`）
- 1-form / 2-form / 3-form の表記は `$1$-form`（数字と形式名の間にハイフン）
- 計量の導入前は $\ast$ の定義を保留する（第5章まで内積を「召喚」しない）
- 物理量の次元は適宜記載し、SI単位系を基本とする
- 本文・見出し・チェックポイントに emoji（💡等）は使用しない
- 文体は各章で統一する。詳しくは [STYLE.md §6](./STYLE.md) を参照
