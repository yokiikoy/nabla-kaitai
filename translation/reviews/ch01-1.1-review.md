## Important Translation Decisions

### 1. `row vector` / `column vector`

The Japanese source uses 横ベクトル / 縦ベクトル. The English version uses `row vector` / `column vector` throughout, following the style guide.

### 2. `linear form` and `$1$-form`

The Japanese 一次形式 is translated as `linear form`, with `$1$-form` introduced immediately as the equivalent technical term. This is intended to help both elementary readers and readers coming from differential forms.

### 3. Operator terminology

The Japanese note distinguishes 演算子 / 作用素 / 関数 / 写像. The English version uses `operator`, `functional`, `function`, and `map`. This avoids the awkward duplicate `operator/operator` issue that appeared in the old draft.

### 4. Conventional integral notation

The English version keeps the distinction that the $dx$ at the end of $\int_a^b f(x)\,dx$ remains conventional notation, while bare $dx$ in the main text is treated as an operator / row vector / $1$-form.
