# 第1章：1次元の微積分を「行列」で解体する

#### §1.1 数学者の1次元、物理学者の1次元
高校で $\int f(x) dx$ という1次元の積分を習ったとき、我々の頭には「$x$軸という1本の線」が浮かんだ。数学の教科書はそれで十分だ。彼らは1次元空間 $\mathbb{R}^1$ という自己完結した抽象世界を仮定し、その上で論理を積み上げる。点は実数 $x$、変位は実数 $\Delta x$、積分は「関数×微小幅」の極限として定義される。すべてが完結している。
しかし、我々は物理学者である。
我々が扱う現実の物理空間は、常に3次元だ。質点が直線上を運動しているように見えても、それは「架空の1次元空間」にいるのではなく、「3次元空間 $\mathbb{R}^3$ の中で、たまたま $y$ 方向と $z$ 方向への変位が観測されない（あるいは無視できる）断面」を見ているに過ぎない。
例えば、摩擦のない直線レール上を滑る台車を考えよう。我々は「これは $x$ 軸方向の1次元運動だ」と言うが、実際には：
* レールは3次元空間内に設置されている
* 台車は微小に上下に揺れているかもしれない
* 空気抵抗による横方向の微小変動もある

物理学者の「1次元運動」とは、**3次元空間内で特定の方向への変位が支配的であり、他の方向の変位が無視できるほど小さいか、系の対称性によって厳密にゼロに拘束されている状況**を指す。
したがって、物理学者が「1次元の微小変位」と呼ぶものの真の姿は、単なるスカラー $\Delta x$ ではなく、次のような**3成分のタテベクトル（列ベクトル）**であるべきだ：
$$\mathbf{v} = \begin{pmatrix} \Delta x \\ 0 \\ 0 \end{pmatrix}$$

この第2成分・第3成分のゼロは、「無視されている」あるいは「存在しない」という消極的な意味ではない。**「我々が今、$x$軸方向の運動だけに注目し、他の成分を測定対象から意図的に除外している」という積極的な選択の結果**なのである。
この「物理学者としての3次元前提」こそが、積分記号の末尾にへばりついている $dx$ という記号の真の姿を暴き出す鍵となる。次節では、この視点から $dx$ を「微小量」から「行列」へと解体していく。

### §1.2 リーマン積分のベクトル解剖 — 区分求積法を行列作用として見る
前節で、物理的な微小変位を3次元のタテベクトル $\mathbf{v} = (\Delta x, 0, 0)^T$ と捉え直した。この視点を持って、今度は高校以来慣れ親しんだリーマン積分のプロセスを徹底的に解体し、その中に潜む「行列としての $dx$」を炙り出してみよう。

#### 1.2.1 リーマン和の標準的構成（復習）
関数 $f(x)$ の区間 $[a, b]$ における定積分は、次のように定義される：
1. 区間を $n$ 個の小区間に分割： $a = x_0 < x_1 < \cdots < x_n = b$
2. 小区間の幅を $\Delta x_i = x_i - x_{i-1}$
3. 各小区間から代表点 $\xi_i \in [x_{i-1}, x_i]$ を選ぶ
4. リーマン和 $R_n = \sum_{i=1}^n f(\xi_i) \Delta x_i$ を作る
5. 分割を細かくする極限をとる： $\int_a^b f(x)dx = \lim_{n\to\infty} R_n$

この教科書的な説明では、$\Delta x_i$ は「微小な幅」というスカラー量だ。しかし、我々はもう一歩踏み込めるはずだ。

#### 1.2.2 変位ベクトル $\mathbf{v}_i$ の導入
区間 $[x_{i-1}, x_i]$ における質点の変位を、物理学者らしく3次元のタテベクトルで記述しよう：
$$\mathbf{v}_i = \begin{pmatrix} \Delta x_i \\ 0 \\ 0 \end{pmatrix}$$

この $\mathbf{v}_i$ こそが、質点が区間 $[x_{i-1}, x_i]$ を移動する際の「真の変位」である。今は直線運動を考えているので $y, z$ 成分はゼロだが、それは条件ではなく結果としてゼロになっているだけだ。

#### 1.2.3 $dx$ 行列の登場 — 成分抽出器としての働き
ここで、前節で予告した「行列としての $dx$」の、**デカルト座標系 $(x, y, z)$ における具体的な表現**を導入しよう：
$$dx \quad\text{の表現}\quad = \begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$$

厳密には $dx$ は座標の取り方に依存しない幾何学的実体であり、上式は**デカルト座標での行列表現**にすぎない。第1.5節で成分が変わるのはこの表示の話である。

この $1 \times 3$ 行列（ヨコベクトル）を、我々は**デカルト座標系における $dx$ の行列表現**と呼び、同じ記号 $dx$ で表すことにする。これを、変位ベクトル $\mathbf{v}_i$ に左から作用させてみよう：
$$dx\,\mathbf{v}_i = \begin{pmatrix} 1 & 0 & 0 \end{pmatrix} \begin{pmatrix} \Delta x_i \\ 0 \\ 0 \end{pmatrix} = 1\cdot\Delta x_i + 0\cdot 0 + 0\cdot 0 = \Delta x_i$$

**これが決定的な瞬間だ**：
* 左辺：行列 $dx$ が変位ベクトル $\mathbf{v}_i$ に作用する「代数的操作」
* 右辺：従来のリーマン和に現れる「小区間の幅 $\Delta x_i$」

つまり、リーマン和の $\Delta x_i$ は、無から生じた微小量ではなく、**行列$dx$が物理的変位ベクトル$\mathbf{v}_i$から$x$成分だけを抽出した結果**なのである。

#### 1.2.4 リーマン和のベクトル再解釈
この視点でリーマン和を書き直すと：
$$R_n = \sum_{i=1}^n f(\xi_i) \cdot \bigl( dx\,\mathbf{v}_i \bigr)$$

さらに進んで、各小区間で定義される新しい行列を考えよう：
$$f(\xi_i)\,dx = \begin{pmatrix} f(\xi_i) & 0 & 0 \end{pmatrix}$$

これは「場所 $\xi_i$ における測定器」であり、変位ベクトル $\mathbf{v}_i$ に作用させると：
$$\bigl(f(\xi_i)\,dx\bigr)\,\mathbf{v}_i = f(\xi_i) \cdot \Delta x_i$$

まさにリーマン和の各項そのものが得られる。

#### 1.2.5 極限への移行 — 連続的な作用としての積分
分割を無限に細かくする極限 $n\to\infty$ では：
* 変位ベクトル $\mathbf{v}_i$ は微小になり、連続的な接ベクトル場 $\mathbf{v}(x)$ へ
* 行列 $f(x)dx = \begin{pmatrix} f(x) & 0 & 0 \end{pmatrix}$ は各点 $x$ で定義される
* リーマン和の極限は、この行列を経路全体にわたって適用し続ける操作となる

$$\int_a^b f(x)dx = \lim_{n\to\infty} \sum_{i=1}^n \bigl(f(\xi_i)dx\bigr)\,\mathbf{v}_i$$

この右辺を、我々は新しい記号で次のように解釈する：
$$= \int_{\text{経路}} \bigl(f(x)dx\bigr)\,\mathbf{v}$$

ここで $\mathbf{v}$ は、経路の各点における「微小変位の方向と大きさ」を表すタテベクトル場である。直線運動の場合、$\mathbf{v} = (1, 0, 0)^T$（単位変位）と取れる。

#### 1.2.6 物理的解釈 — 仕事の計算を例に
物理的な具体例として、直線上の質点に力 $F(x)$ が作用する場合の仕事計算を考えよう：
$$W = \int_a^b F(x)dx$$

従来の解釈：
* $F(x)$：位置 $x$ での力の大きさ
* $dx$：微小な変位の大きさ
* $F(x)dx$：微小仕事

新しい解釈：
* $\mathbf{v} = (\Delta x, 0, 0)^T$：物理的変位ベクトル
* $F(x)dx = \begin{pmatrix} F(x) & 0 & 0 \end{pmatrix}$：「変位の$x$成分を取り出し，力$F(x)$で重み付けする行列」
* $(F(x)dx)\,\mathbf{v} = F(x)\Delta x$：ベクトル的変位から抽出された $x$ 方向の仕事

この視点の強みは、**力が$y$方向にも成分を持つ一般的な場合に自然に拡張できる**点だ。次章で $dy$ を導入すれば、$F_x dx + F_y dy$ という形で2次元の仕事を統一的に扱える。

#### 【用語の導入：一次形式（1-form）】

ここまで、我々は $dx$ を「変位ベクトル（タテベクトル）に作用して特定の成分を抽出し、スカラー（実数）を返すヨコベクトル」として定義してきた。このような、ベクトルを食べてスカラーを吐き出す線形な測定器のことを、微分幾何学や現代物理学では**一次形式**（英語では **1-form** または **covector**）と呼ぶ。本稿で「行列としての $dx$」と呼んできたものは、まさにこの一次形式（1-form）に他ならない。

命名の由来は単純だ：

* **「一次」**：変位ベクトルを**一次（線形）**に処理するから
* **「形式」**：「測定の形式」「作用の形式」を意味する

これ以降、この測定器のことを「行列」とも「一次形式（1-form）」とも呼ぶことにする。どちらの呼び方も、同じ実体を指している。

【本書での用語ルール】

* 主な呼称：**「一次形式」**
* 英語表記を併記する場合：**「一次形式（1-form）」**
* 初出時以外は「1-form」単独使用も可

#### 1.2.7 まとめ — リーマン積分のベクトル解剖の成果
本節で明らかになったのは：
1. **$\Delta x_i$の正体**：それは単なる「幅」ではなく、行列 $dx$ が物理的変位ベクトルから抽出した $x$ 成分である。
2. **リーマン和の本質**：各小区間で「スカラー倍された行列 $f(\xi_i)dx$」を変位ベクトルに作用させ、その結果を足し上げる操作。
3. **積分の新しい見方**：行列場 $f(x)dx$ を経路上で連続的に適用し、その作用の総和を得るプロセス。

この「ベクトル解剖」により、積分は単なる面積計算から、「物理的変位を行列で測定し、その結果を集計する代数的操作」へと昇華した。

**【注記：記号 $dx$ の2つの意味について】**
本書では、$dx$ という記号を2つの異なる意味で使い分ける。従来の物理的慣習である「タテベクトル $\mathbf{v} = (dx, dy, dz)^T$ における $dx$（変位の$x$成分、スカラー）」ではなく、「$x$成分を抽出する測定器（行列）」として $dx$ を定義・使用する。この「測定器」としての $dx$ が本章の主役である。このパラダイムシフトを念頭に置いて読み進めていただきたい。

次節では、この視点を関数の微分へと拡張し、全微分 $df$ を行列として定義していく。

### §1.3 全微分 $df$ — 変化率をエンコードした行列
前節では，リーマン積分を「行列 $f(x)dx$ の変位ベクトルへの作用の集計」として解剖した。この節では，その考え方を関数自体の微分へと拡張し，**全微分$df$を行列として定義する**。これにより，「微分」という操作が，単なる「変化率の計算」から「変化率を成分に持つ行列の構成」へと根本的に変貌する。

#### 1.3.1 微分可能性のベクトル表現
関数 $f(x)$ が点 $x_0$ で微分可能であるとは，次の一次近似が成り立つことである：
$$\Delta f = f(x_0 + \Delta x) - f(x_0) = f'(x_0) \Delta x + o(|\Delta x|)$$
$$\quad (|\Delta x| \to 0)$$

ここで $\Delta x$ はスカラーだが，我々はこれを前節同様，3次元の物理的変位ベクトルとして捉え直す：
$$\mathbf{v} = \begin{pmatrix} \Delta x \\ 0 \\ 0 \end{pmatrix}$$

すると，関数の変化 $\Delta f$ は，この変位ベクトル $\mathbf{v}$ によって引き起こされる効果と見なせる。

#### 1.3.2 $df$ の行列定義 — 変化率のエンコーディング
点 $x_0$ における関数 $f$ の**全微分** $df|_{x_0}$ を，次の $1 \times 3$ 行列（ヨコベクトル）として定義する：
$$df|_{x_0} := f'(x_0) \, dx = \begin{pmatrix} f'(x_0) & 0 & 0 \end{pmatrix}$$

この行列の構成要素を仔細に見よう：
* $f'(x_0)$：関数 $f$ の点 $x_0$ における変化率（スカラー）
* $dx = \begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$：$x$成分抽出器のデカルト行列表現（前節定義）

両者の積（スカラー倍）によって得られる $df|_{x_0}$ は，「変化率情報を特定の方向（$x$方向）へ向けてエンコードした測定器」である。

#### 1.3.3 $df$ の作用 — 変位から変化量への変換
この行列 $df|_{x_0}$ を，変位ベクトル $\mathbf{v} = (\Delta x, 0, 0)^T$ に左から作用させると：
$$df|_{x_0}(\mathbf{v}) = \begin{pmatrix} f'(x_0) & 0 & 0 \end{pmatrix} \begin{pmatrix} \Delta x \\ 0 \\ 0 \end{pmatrix} = f'(x_0) \Delta x$$

得られるのは，関数 $f$ の一次変化量 $f'(x_0) \Delta x$ そのものである。

**重要な認識の転換**：
* 従来：$df = f'(x)dx$ は「微小変化量」の形式的な表現
* 現在：$df|_{x_0}$ は具体的な行列であり，$\mathbf{v}$ に作用させて初めて変化量を出力する**演算子**

$df$ それ自体は変化量ではない。**変化量を生成する「装置」**なのである。

#### 1.3.4 具体例： $f(x) = x^2$ の場合
具体的に関数 $f(x) = x^2$ で考えてみよう。微分係数は $f'(x) = 2x$ だから，点 $x_0 = 3$ における全微分は：
$$df|_{x=3} = 6 \, dx = \begin{pmatrix} 6 & 0 & 0 \end{pmatrix}$$

この行列が意味すること：
* 「今いる点（$x=3$）では，$x$方向の変位に対して，関数値はその6倍の感度で変化する」
* ただし，この感度は $x$ 方向にしか働かない（$y$, $z$方向の変位には反応しない）

変位ベクトル $\mathbf{v} = (0.1, 0, 0)^T$ （$x$方向に0.1だけ移動）に作用させると：
$$df|_{x=3}(\mathbf{v}) = \begin{pmatrix} 6 & 0 & 0 \end{pmatrix} \begin{pmatrix} 0.1 \\ 0 \\ 0 \end{pmatrix} = 0.6$$

実際，$f(3.1) - f(3) = 9.61 - 9 = 0.61$ であり，一次近似 $0.6$ はよく一致している。

#### 1.3.5 微積分学の基本定理の行列解釈
全微分 $df$ のこの新しい解釈は，微積分学の基本定理に新たな光を当てる。
区間 $[a, b]$ に沿った $df$ の積分を考えよう。前節のアプローチに従えば：
$$\int_{[a, b]} df = \int_a^b df|_{\gamma(t)}(\gamma'(t)) \, dt$$

ただし $\gamma: [a, b] \to \mathbb{R}^3$ は $\gamma(t) = (t, 0, 0)$ とし，その速度ベクトルは $\gamma'(t) = (1, 0, 0)^T$ である。すると：
$$\int_{[a, b]} df = \int_a^b \begin{pmatrix} f'(t) & 0 & 0 \end{pmatrix} \begin{pmatrix} 1 \\ 0 \\ 0 \end{pmatrix} dt = \int_a^b f'(t) dt$$

一方，基本定理によればこの右辺は $f(b) - f(a)$ に等しい。つまり：
$$\int_{[a, b]} df = f(b) - f(a)$$

これを言葉で言い換えれば：
**局所的な変化率行列$df$を経路全体にわたって適用し集計すると，大域的な変化量$f(b)-f(a)$が得られる**
これが，基本定理の行列による解釈である。

#### 1.3.6 なぜ行列表示が優れているか — 拡張性の観点から
$df$ を行列として定義する利点は，**多次元への自然な拡張**にある。
1変数では： $df = f'(x) dx = \begin{pmatrix} f'(x) & 0 & 0 \end{pmatrix}$
2変数関数 $f(x, y)$ では（次章で詳述）： $df = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy = \begin{pmatrix} \frac{\partial f}{\partial x} & \frac{\partial f}{\partial y} & 0 \end{pmatrix}$
3変数では： $df = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy + \frac{\partial f}{\partial z} dz = \begin{pmatrix} \frac{\partial f}{\partial x} & \frac{\partial f}{\partial y} & \frac{\partial f}{\partial z} \end{pmatrix}$

このように，**次元が増えても形式は変わらない**。ただ行列の成分（情報をエンコードする方向）が増えるだけだ。これが「代数の武器」としての威力である。

#### 1.3.7 物理的直感 — 「感度行列」としての $df$
物理学者にとって，$df$ の行列表示は極めて直感的だ。
例えば，温度場 $T(x, y, z)$ を考えよう。点 $\mathbf{p}$ における全微分： $dT|_{\mathbf{p}} = \begin{pmatrix} \frac{\partial T}{\partial x} & \frac{\partial T}{\partial y} & \frac{\partial T}{\partial z} \end{pmatrix}$
これは「点 $\mathbf{p}$ における温度の感度行列」である。これを変位ベクトル $\mathbf{v} = (\Delta x, \Delta y, \Delta z)^T$ に作用させれば： $dT|_{\mathbf{p}}(\mathbf{v}) = \frac{\partial T}{\partial x} \Delta x + \frac{\partial T}{\partial y} \Delta y + \frac{\partial T}{\partial z} \Delta z$
これは，変位 $\mathbf{v}$ による温度変化の最良の一次近似を与える。

#### 1.3.8 まとめ
本節で確立したのは：
1. **全微分の行列定義**： $df|_{x_0} = f'(x_0) dx = \begin{pmatrix} f'(x_0) & 0 & 0 \end{pmatrix}$
2. **作用の解釈**： $df$ はそれ自体が変化量ではなく，変位ベクトルに作用して変化量を出力する「演算子」
3. **基本定理の再解釈**： $\int_{[a,b]} df = f(b)-f(a)$ は，局所的演算子の積分が大域的変化を与えるという原理
4. **拡張性**： この形式は多次元へそのまま拡張され，統一的な扱いを可能にする

$df$ を行列と見なすことで，微分と積分が「演算子の適用とその集計」という一貫した枠組みに収まった。次節では，この視点から積分そのものを再構築し，基本定理をより深く理解する。

### §1.4 積分の再解釈 — 行列作用の集計
前節で，全微分 $df$ を「変化率行列」として定義した。この節では，その行列を**経路に沿って適用し続ける操作**として積分を捉え直す。これにより，積分は単なる「和の極限」から，「行列作用の連続的な適用とその集計」という代数的操作へと昇華する。

#### 1.4.1 積分の二つの顔：リーマン和と行列作用
従来のリーマン積分（§1.2）は： $\int_a^b f(x)dx = \lim_{n\to\infty} \sum_{i=1}^n f(\xi_i) \Delta x_i$
これを前節の言葉で書き換えると： $\int_a^b f(x)dx = \lim_{n\to\infty} \sum_{i=1}^n f(\xi_i) \bigl(dx\,\mathbf{v}_i\bigr)$ ただし $\mathbf{v}_i = (\Delta x_i, 0, 0)^T$
さらに，$f(x)dx$ を一つの行列と見なせば： $= \lim_{n\to\infty} \sum_{i=1}^n \bigl(f(\xi_i)dx\bigr)\,\mathbf{v}_i$
この極限が意味するのは，**行列場$f(x)dx$を，経路に沿って連続的に変位ベクトルに作用させ，その結果を無限に足し合わせる操作**である。

#### 1.4.2 行列場の連続的適用 — 新しい記法の提案
経路（この場合は区間 $[a, b]$）に沿って，行列 $f(x)dx$ を連続的に適用することを，次のように表そう：
$$\int_{[a, b]} f(x)dx = \int_{t_a}^{t_b} \bigl(f(\gamma(t))dx\bigr)\,\gamma'(t) \, dt$$
ここで，$\gamma: [t_a, t_b] \to \mathbb{R}^3$ を $\gamma(t) = (t, 0, 0)$ とすると，$\gamma'(t) = (1,0,0)^T$ は質点の速度ベクトル（位置の時間変化率）である。

注意すべきは，末尾の $dt$ も決して「微小な時間」ではないということだ。これもまた，時間軸という1次元空間における一次形式（時間の測定器）である。つまりこの積分は，「速度ベクトルに空間の感度行列を作用させて『単位時間あたりの変化率』を出力し，**その変化率に時間軸的測定器 $dt$ を作用させて連続的に集計していく**」という，完全に代数的な操作として再定義されるのである。ここにはもはや「微小な幅」という曖昧な実体は一切介在しない。

**【型の変化に注目】**：この過程で，作用の「型」が重要な転換を迎える。$\bigl(f(\gamma(t))dx\bigr)$ は空間の一次形式（行列）であり，これに\,$\gamma'(t)$ を作用させた結果 $\bigl(f(\gamma(t))dx\bigr)\,\gamma'(t)$ は**純粋なスカラー値関数**（時間 $t$ の関数）となる。つまり，空間に関する「測定」はここで完了し，出力されたスカラー関数に対して，今度は**時間軸上の測定器 $dt$ による積分**が行われるのである。

#### 1.4.3 全微分の積分 — 基本定理の深層解釈
より本質的なのは，全微分 $df$ の積分である。§1.3で定義したように $df = f'(x)dx$ だから：
$$\int_{[a, b]} df = \int_{[a, b]} f'(x)dx$$

$\gamma(t) = (t, 0, 0)$，$\gamma'(t) = (1,0,0)^T$ を用いて行列作用として解釈すると：
$$= \int_{t_a}^{t_b} \bigl(f'(\gamma(t))dx\bigr)\,\gamma'(t) \, dt = \int_{t_a}^{t_b} f'(\gamma(t)) \, dt$$
一方，微積分学の基本定理から： $\int_{[a, b]} df = f(b) - f(a)$

**ここに現れた深い事実**：
* 左辺：局所的な変化率行列 $df$ を経路全体にわたり適用・集計
* 右辺：大域的な状態変化 $f(b)-f(a)$

つまり，**局所的演算子の連続適用が，大域的変化を生み出す**という原理がここにある。

#### 1.4.4 物理的実例：保存力の仕事
具体例として，保存力場中での仕事計算を考えよう。1次元の場合，力は位置の関数 $F(x)$ で，ポテンシャルエネルギー $U(x)$ と $F(x) = -U'(x)$ の関係にある。
質点が $a$ から $b$ まで移動するとき，力がする仕事は： $W = \int_a^b F(x)dx$
これを微分形式で書けば： $W = -\int_a^b U'(x)dx = -\int_{[a, b]} dU$
基本定理より： $W = -\bigl(U(b) - U(a)\bigr) = U(a) - U(b)$

これを新しい視点で解釈すると：
1. $dU = U'(x)dx$ は「ポテンシャルの感度行列」
2. これを経路に沿って適用・集計すると，ポテンシャルエネルギーの変化量
3. その負の値が，力がした仕事

**重要な認識**：積分 $\int dU$ は，単なる計算ではなく，「ポテンシャルの感度行列を適用して，総変化量を得る**測定プロセス**」なのである。

#### 1.4.5 線積分への一般化の萌芽
今は1次元の直線経路だが，この考え方は曲線経路へ自然に拡張できる。
一般の曲線 $\gamma: [t_0, t_1] \to \mathbb{R}^3$ に沿った積分を： $\int_\gamma f(x)dx = \int_{t_0}^{t_1} \bigl(f(\gamma(t))dx\bigr)\,\gamma'(t) \, dt$
と定義できる。ただし $dx$ のデカルト行列表現は依然として $\begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ ですが，$\gamma'(t)$ は曲線の接ベクトル（必ずしも $x$ 方向とは限らない）。

この定義の美点は，**被積分関数$f(x)dx$と，積分経路$\gamma$が分離されている**ことだ：
* $f(x)dx$：場の情報（「何を測るか」）
* $\gamma$：測定経路（「どこで測るか」）
* $\gamma'(t)$：測定方向（「どの向きで測るか」）

#### 1.4.6 無限小の代数的操作としての積分
この視点では，積分記号 $\int$ は単なる「和の極限」ではなく，**二つの代数的対象の相互作用を規定する演算子**と見なせる：
1. **微分形式** $\omega = f(x)dx$：場の情報を行列としてエンコード
2. **曲線** $\gamma$：積分経路とその接ベクトル場
3. **積分** $\int_\gamma \omega$：微分形式 $\omega$ を，曲線の接ベクトル場に沿って適用し，結果を集計

この枠組みは，高次元の面積分・体積分へも拡張可能だ。次章で $dy$, $dz$ を導入すれば，$dx \wedge dy$ のような「2次形式」を定義でき，それを曲面にわたって積分できる。

#### 1.4.7 歴史的視点：ライプニッツの記法の真意
ライプニッツが $dx$, $dy$ という記号を導入した時，彼はこれらを「無限小」として直感的に扱った。現代の我々は，その直感を厳密な行列表示として実現したと言える。
ライプニッツの記法 $df = f'(x)dx$ は，単なる形式的等式ではない：
* $dx$：無限小変位（ライプニッツ）→ $x$成分抽出行列（現代）
* $df$：無限小変化（ライプニッツ）→ 変化率行列（現代）

**ライプニッツの天才は，微分・積分が本質的に代数的操作であることを見抜いていた**。我々はただ，彼の直感に線形代数という厳密な基礎を与えたに過ぎない。

#### 1.4.8 まとめ
本節で確立した積分の新しい解釈：
1. **積分の本質**：微分形式（行列）を経路上で連続的に適用し，その作用を集計する操作
2. **基本定理の深層意味**：局所的変化率行列の積分が，大域的変化量を与える
3. **物理的解釈**：保存力の仕事は，ポテンシャルの感度行列の適用・集計として理解できる
4. **拡張性**：この枠組みは，曲線・曲面への積分へ自然に拡張される

積分はもはや「面積を求める技巧」ではない。それは，**微分形式という代数的対象と，幾何学的対象（曲線）との相互作用を記述する普遍的な言語**なのである。
次節では，この強力な枠組みが依存している暗黙の前提——「デカルト座標系」の特権性——を明らかにし，その先にあるより一般的な理論への扉を開く。

### §1.5 「デカルトの特権」と物理学の現実

本章を通じて，我々は $dx$ の**デカルト行列表現** $\begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ を用いて積分を「行列作用の集計」として再構築してきた。このアプローチの威力は疑いようもないが，物理学者としてここで一つの厳粛な事実を認めなければならない。それは，この美しい行列表示の成分が場所によらず一定に保たれるという性質は，我々が**特別に選ばれた座標系**——デカルト座標（直交直線座標）——の中にいるからに他ならない，という事実である（測定器としての $dx$ 自体は §1.2.3 で述べたとおり座標に依存しない幾何学的実体だ）。

#### 1.5.1 デカルト座標の「特権」とは何か

デカルト座標系が物理学において特別な地位を占める理由は，それが**最も単純で，空間のどこでも性質が変わらない**座標系だからだ。この「平坦な方眼紙」の上では：
1. **基底ベクトルが一定**：$\hat{e}_x, \hat{e}_y, \hat{e}_z$ は空間のどこでも同じ向き・同じ大きさを持つ。
2. **行列表現が場所によらない**：$x$ 方向の単位変位がどこでも同じなので，$dx$ のデカルト行列表現が空間のどこでも $\begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ のまま変わらない。

#### 1.5.2 物理学の現実は「四角い」とは限らない

しかし，現実の物理現象，特に電磁気学や流体力学の問題を解くとき，世界は必ずしもデカルト座標にとって都合よくできてはいない。

直線状のアンペア回路の周りに生じる磁場を計算するときや，円形のパイプの中を流れる流体の速度場を記述するとき，我々はデカルト座標ではなく**「円柱座標 $(r, \theta, z)$」**や**「球座標 $(r, \theta, \phi)$」**といった直交曲線座標を使わざるを得ない。

では，座標系を円柱座標に変えたとき，デカルトでの $dx$ の行列表現 $\begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ はどうなってしまうのだろうか？

#### 1.5.3 座標変換による $dx$ の変貌

デカルト座標 $(x, y, z)$ から，円柱座標 $(r, \theta, z)$ へ変換する場面を考えよう。変換則は：
$$
x = r\cos\theta,\quad y = r\sin\theta,\quad z = z
$$

微分の連鎖律から，$dx$ は次のように書き換えられる：
$$
dx = \frac{\partial x}{\partial r}dr + \frac{\partial x}{\partial \theta}d\theta + \frac{\partial x}{\partial z}dz = \cos\theta\, dr - r\sin\theta\, d\theta
$$

驚くべきことに，$dx$ という測定器（幾何学的実体）そのものは不変であるにもかかわらず，それを円柱座標系の基底 $(dr, d\theta, dz)$ に対する成分として表現しようとした途端，デカルト座標での定数成分 $\begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ から，場所 $(r, \theta)$ に依存する関数を成分に持つ行列へと姿を変えるのである。対象そのものは不変であっても，「基準となる基底が変われば，その行列表現（成分）も変わる」 ——これが基底変換の核心である。

#### 1.5.4 なぜ代数的な武器が必要なのか

この事実こそが，我々が微積分を「代数」として再構築しなければならない最大の理由である。

従来の「$\Delta x$ は微小な幅である」という素朴なイメージのままでは，座標系が曲がった瞬間に直感が破綻する。しかし，$dx$ を「変位ベクトルから成分を抽出する一次形式」として定義しておけば，座標系が変わっても**「基底変換に伴う行列の成分変化」という線形代数の単純なルール**に従って，機械的かつ厳密に計算を進めることができる。

本書の後半（第III部・第IV部）で電磁気学や流体力学の複雑な問題に挑むとき，この「座標に依存しない代数構造」がどれほど強力な武器になるかを目の当たりにするだろう。

### §1.6 基底変換の気づき（演習と展望）

本章の最後に，読者自身の手で「座標変換」を体験し，その物理的意味を考えてもらおう。数学的な抽象論に溺れるのではなく，具体的な計算を通じて，基底変換が何を意味するかを体感することが目的である。

#### 1.6.1 演習問題：円柱座標での測定

**問題設定**
前節で見た通り，円柱座標 $(r, \theta, z)$ における $dx$ の行列表示は以下のようになる：
$$
dx = \begin{pmatrix} \cos\theta & -r\sin\theta & 0 \end{pmatrix}
$$
このとき，次の問いに答えよ。

**問1**  
円柱座標空間内の点 $P(r=2, \theta=\pi/6, z=0)$ に質点があるとする。この質点が，$r$ 方向に $0.1$ だけ微小変位した。この変位ベクトル $\mathbf{v}$ を円柱座標の成分で表せ。

**問2**  
問1の変位ベクトル $\mathbf{v}$ に対して，点 $P$ における行列 $dx$ を作用させよ。（$\cos(\pi/6) = \sqrt{3}/2$ を用いよ）

**問3**  
問2で計算した結果（$dx\,\mathbf{v}$）は，物理的に何を意味しているか説明せよ。

#### 1.6.2 解答と解説

**問1の解答**
変位は $r$ 方向に $0.1$，$\theta$ 方向と $z$ 方向にはゼロなので，円柱座標の基底におけるタテベクトルとして次のように書ける：
$$
\mathbf{v} = \begin{pmatrix} 0.1 \\ 0 \\ 0 \end{pmatrix}
$$

**問2の解答**  
点 $P$ における行列 $dx$ は，$\theta = \pi/6, r=2$ を代入して：
$$
dx|_P = \begin{pmatrix} \cos(\frac{\pi}{6}) & -2\sin(\frac{\pi}{6}) & 0 \end{pmatrix} = \begin{pmatrix} \frac{\sqrt{3}}{2} & -2 \times \frac{1}{2} & 0 \end{pmatrix} = \begin{pmatrix} \frac{\sqrt{3}}{2} & -1 & 0 \end{pmatrix}
$$
重要なのは，第2成分の $-1$ が $r=2$ に由来していることだ。この $-1$ は単なる無次元数ではなく，**「長さの次元」を隠し持っている**。これが次元解析の鍵となる。
これを変位ベクトル $\mathbf{v}$ に作用させると：
$$
dx|_P\,\mathbf{v} = \begin{pmatrix} \frac{\sqrt{3}}{2} & -1 & 0 \end{pmatrix} \begin{pmatrix} 0.1 \\ 0 \\ 0 \end{pmatrix} = 0.1 \times \frac{\sqrt{3}}{2} \approx 0.0866
$$

**問3の解答（物理的意味）**  
この結果は，**「円柱座標において外側（$r$方向）へ $0.1$ だけ進むという運動は，デカルト座標の $x$ 軸方向から見ると約 $0.0866$ の前進に相当する」**という物理的事実を表している。

**【次元解析の深い考察】**
計算結果 $dx|_P\,\mathbf{v} = 0.1 \times \frac{\sqrt{3}}{2}$ を見ると，$r$方向成分$0.1$（長さの次元）と，無次元の係数$\frac{\sqrt{3}}{2}$の積となっており，出力は確かに長さの次元を持つ。
しかし，もし$\theta$方向の変位$\mathbf{v} = (0, 0.1, 0)^T$（角度変位$0.1$ラジアン）を入力したとすると：
$$dx|_P\,\mathbf{v} = \begin{pmatrix} \frac{\sqrt{3}}{2} & -1 & 0 \end{pmatrix} \begin{pmatrix} 0 \\ 0.1 \\ 0 \end{pmatrix} = -0.1$$
この場合，無次元の入力$0.1$に対して，出力は$-0.1$という長さの次元を持つ値になる。

ここに**一次形式**の驚くべき性質がある： $dx$ の行列成分自体が $r$ を含む関数であり，入力が座標成分（次元がバラバラでも）であっても，出力は常に「$x$ 方向の長さ」という正しい物理的次元を持つように自動調整される。**一次形式は，座標系の歪みを吸収し，物理的に意味のある測定値を出力する「賢い測定器」**なのである。

**測定器の較正（キャリブレーション）としての基底変換**  
デカルト座標の $dx = \begin{pmatrix} 1 & 0 & 0 \end{pmatrix}$ は，「純粋な$x$方向の変位を1と測定する装置」である。これを円柱座標で使おうとすると，装置は「$r$方向や$\theta$方向の変位も$x$成分に影響する」ことを考慮しなければならない。
つまり，座標系を変えるということは，**測定器（行列）の目盛りを場所ごとに較正し直す作業**に他ならない。これが基底変換の正体である。

#### 1.6.3 本書の今後の展望

本章では $dx$ だけを扱い，$y, z$ 方向は常に「断面」として無視してきた。
次章から始まる**第I部（基礎篇）の後半**では，この自己制限を解き放つ。$dy = \begin{pmatrix}0&1&0\end{pmatrix}$, $dz = \begin{pmatrix}0&0&1\end{pmatrix}$ を正式に導入し，3次元空間全体を記述する**一次形式（1-form）**の理論を完成させる。さらに，それらを掛け合わせる「外積（ウェッジ積 $\wedge$）」を導入する。

続く**第II部（解析篇）**では，微分演算子 $d$ を導入し，ベクトル解析における「勾配（grad）」「回転（rot）」「発散（div）」が，実はたった一つの代数的操作のバリエーションに過ぎないことを証明する。

そして**第III部・第IV部**において，我々はこの代数の武器を駆使して「ストークスの定理」を鮮やかに証明し，最終的には**マクスウェル方程式**や**流体力学の基礎方程式**を，微分形式という極めて美しく強力な言語で記述し直すことになる。

3次元ユークリッド空間の真の姿を解き明かす旅へ，いざ出発しよう。
